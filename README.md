# ⚡ SpeedFusion Pro

تطبيق ويب تقدّمي (PWA) **يقيس فعلياً** سرعة الإنترنت، ويقارن خوادم DNS، ويفحص الاتصال وحالة البطارية. بلا أرقام وهمية ولا إعلانات.

**الرابط:** https://bakil309275-cell.github.io/speedfusion-pwa/

## ما الذي يفعله فعلاً
| الميزة | كيف تعمل |
|---|---|
| اختبار السرعة | تحميل متوازي (4 مسارات) ورفع عبر XHR إلى `speed.cloudflare.com`، مع عداد حي وحساب بعد فترة إحماء 1 ثانية |
| زمن الاستجابة والتذبذب | 12 طلباً متتالياً، الوسيط للاستجابة ومتوسط الفروق للتذبذب |
| مقارنة DNS | استعلامات DNS-over-HTTPS حقيقية (RFC 8484) لـ Cloudflare وGoogle وQuad9 وAdGuard وOpenDNS، ثم ترتيبها بالوسيط |
| فحص الاتصال | `cdn-cgi/trace`: IP، الدولة، مركز البيانات، إصدار TLS/HTTP، WARP |
| الشبكة والبطارية | `navigator.connection` و`Battery Status API` (حيث يدعمها المتصفح) |
| السجل | حفظ محلي، إحصائيات، رسم بياني، تصدير CSV |
| الاختبار التلقائي | يعمل والتطبيق مفتوح فقط، ويتخطى بيانات الجوال/توفير الطاقة |
| توفير الطاقة / الأسود الكامل | يوقف الحركات والتمويه ويعتمد خلفية سوداء (توفير فعلي في شاشات OLED) |
| PWA | تثبيت، عمل دون اتصال لواجهة التطبيق، تنبيه بالتحديث |

## ما لا يستطيعه (حدود المتصفح)
- تغيير DNS الجهاز، أو «تسريع» الإنترنت، أو تنظيف الذاكرة، أو إطالة البطارية بنسبة محددة. التطبيق يُرشدك لضبط **DNS الخاص** على أندرويد بعد اختيار الأسرع، لكن التفعيل يتم من إعدادات جهازك.
- الاختبار التلقائي في الخلفية والتطبيق مغلق.

## التشغيل محلياً
```bash
git clone https://github.com/bakil309275-cell/speedfusion-pwa.git
cd speedfusion-pwa/docs && python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

## الهيكل
`docs/` هو المصدر الرئيسي. نسخة الجذر مطابقة له ليعمل النشر من أي من المجلدين. بعد أي تعديل نفّذ:
```bash
./sync.sh
```

## الخصوصية
النتائج تبقى على جهازك. الاتصالات الخارجية الوحيدة هي طلبات القياس إلى Cloudflare ومزوّدي DNS (انظر [سياسة الخصوصية](privacy.html)).
